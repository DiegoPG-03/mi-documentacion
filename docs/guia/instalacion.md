# Guía de Instalación

Para comenzar a desarrollar nuestras aplicaciones, necesitamos preparar el entorno de trabajo instalando las herramientas necesarias.

## 1. Java Development Kit (JDK)
El JDK es imprescindible para compilar y ejecutar código en Java.
- Descarga la última versión del JDK desde la página oficial de Oracle o utiliza una distribución como OpenJDK.
- Ejecuta el instalador y sigue los pasos del asistente.

## 2. Apache NetBeans (IDE)
Como entorno de desarrollo integrado (IDE) utilizaremos Apache NetBeans.
- Accede al sitio web oficial y descarga el instalador correspondiente a tu sistema operativo.
- Asegúrate de tener el JDK instalado previamente, ya que NetBeans lo requiere para funcionar.
- Completa la instalación con las opciones por defecto.
